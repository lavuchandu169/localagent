Google sign-in needs your own OAuth Client ID (and sometimes a Client Secret) from Google Cloud Console. Saved locally, used only to sign in.

  1. console.cloud.google.com → create or select a project.
  2. APIs & Services → OAuth consent screen → configure it, add yourself as a test user (or publish to production).
  3. APIs & Services → Credentials → Create Credentials → OAuth client ID → Application type: Desktop app.
  4. Copy the Client ID (and Client Secret, if Google issued one) below.
