Welcome to localagent

A local-first coding agent. Pick a model to get started — here's what each choice in the Model dropdown means:

Coding / Chat (embedded)
Runs entirely on this machine — no data ever leaves it. Free and completely private, but the smaller models can be unreliable on complex, multi-file changes — sometimes describing an edit instead of actually making it.
Claude Sonnet 5 / Opus 5 / Haiku 4.5 (Anthropic API)
The most dependable choice for real work — sends your code to Anthropic over the network in exchange for it. Needs an API key — add one in Settings (gear icon) or it's already built in on official downloads.
Custom server
Point it at your own Ollama, LM Studio, or vLLM server instead.

Google sign-in (top right) is entirely optional — everything works fully signed-out. Signing in just adds automatic backup of your session history to your own Google Drive.
